/api/v1/resume/tailor

Tailor Candidate Resume for Specific Job

Executes the AI resume tailoring harness to generate role-aligned summaries, highlight target tech stack competencies, and rewrite bullet points into high-impact STAR/Google XYZ achievement statements without hallucinating facts.

cURL Example 
curl -X POST "http://localhost:8000/api/v1/resume/tailor" \
  -H "X-API-Key: jf_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "job_title": "Senior Backend Engineer",
    "company": "TechNova Corp",
    "job_description": "We are seeking a Python & FastAPI engineer with experience in PostgreSQL, microservices, and AI integrations.",
    "requirements": ["Python", "FastAPI", "PostgreSQL", "Docker", "AsyncIO"]
  }'
POST

/api/v1/resume/generate-pdf

Generate Raw ATS-Compliant PDF

Accepts a structured TailoredResume payload and immediately renders high-resolution, format-conforming A4 PDF bytes (application/pdf).

Python Example (Save PDF directly) 
import requests

api_key = "jf_live_YOUR_API_KEY"
tailored_data = { ... }  # Output from /api/v1/resume/tailor

response = requests.post(
    "http://localhost:8000/api/v1/resume/generate-pdf",
    headers={"X-API-Key": api_key, "Content-Type": "application/json"},
    json=tailored_data
)

if response.status_code == 200:
    with open("tailored_ats_resume.pdf", "wb") as f:
        f.write(response.content)
    print("Downloaded tailored ATS PDF!")

/api/v1/ats/score

Match & Keyword Scorer

Scores alignment between candidate resume text and target job description using TF-IDF cosine similarity, keyword coverage ratio, and missing skills analysis.

cURL Example 
curl -X POST "http://localhost:8000/api/v1/ats/score" \
  -H "X-API-Key: jf_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "job_description": "Requires Senior Python developer with Docker, Kubernetes, AWS, and PostgreSQL experience.",
    "requirements": ["Python", "Docker", "Kubernetes", "AWS"]
  }'

/api/v1/jobs/extract

Universal Platform Job Scraping

Extracts structured job metadata (title, company, description, location, required keywords) from any job posting URL including LinkedIn, JobStreet, Glints, and arbitrary career pages.

cURL Example 
curl -X POST "http://localhost:8000/api/v1/jobs/extract" \
  -H "X-API-Key: jf_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.jobstreet.co.id/en/job/12345678"
  }'

/api/v1/jobs/auto-discover

Multi-Platform AI Harvesting

Harvests live postings from LinkedIn, JobStreet, Glints, and RemoteOK based on candidate's master profile, automatically filtering irrelevant positions via relevance score threshold.

cURL Example 
curl -X POST "http://localhost:8000/api/v1/jobs/auto-discover" \
  -H "X-API-Key: jf_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "platforms": ["jobstreet", "linkedin", "glints"],
    "min_relevance": 65.0,
    "max_jobs": 5,
    "location": "Indonesia"
  }'
POST

/api/v1/cv/parse-text & /api/v1/cv/upload

  -F "file=@/path/to/candidate_cv.pdf"

/api/v1/apply/execute/{job_id}

Dispatch Playwright Worker

Dispatches asynchronous browser worker to fill in application form fields, upload the tailored PDF CV, and capture confirmation verification screenshots.

cURL Example 
# 1. Dispatch application runner in background
curl -X POST "http://localhost:8000/api/v1/apply/execute/42?headless=true" \
  -H "X-API-Key: jf_live_YOUR_API_KEY"

# 2. Check live execution status & logs
curl -X GET "http://localhost:8000/api/v1/apply/status/42" \
  -H "X-API-Key: jf_live_YOUR_API_KEY"
